# Модерация Яндекс Игр: чек-лист (этап 16.6)

Источник требований — `yandex.ru/dev/games/doc/ru/concepts/requirements` (прочитан 01.10.2026, выжимка по десктопу —
`docs/DESKTOP.md`, раздел 1). **12.10 сверено с редакцией от 09.10.2026** (полный текст прислал пользователь) —
итог в разделе 4. Пункты и их номера меняются: перед отправкой проверить дату редакции на странице.

Обозначения: **код** — сверено по коду 10.10 (сессия 111) и/или selftest; **черновик** — проверить руками в
черновике (16.7a); **решение** — зависит от вас.

## 1. Сверка с игрой по коду (16.6a)

| Тема | Требование | Как у нас (где в коде) | Статус |
|---|---|---|---|
| SDK | SDK подключён и инициализирован | `html/head_include` = `/sdk.js` (`export_presets.cfg`); `YaGames.init` в JS-обёртке `autoload/ysdk.gd` | код |
| Загрузка | `LoadingAPI.ready()` — когда игра готова к игре | меню на экране → `YSDK.loading_ready()` (`scenes/menu/menu.gd`); если SDK ещё не готов — после `init` | код |
| Геймплей | `GameplayAPI.start/stop` по реальному игровому процессу | начало уровня / победа / выход (`game.gd`), окно паузы — stop, продолжить — start; на время рекламы, `game_api_pause` и скрытой вкладки — stop (`YSDK._sync_gameplay`) | код |
| Реклама | Только через SDK; своих баннеров и стики-баннеров нет | `adv.showFullscreenAdv` и `adv.showRewardedVideo`, больше ничего | код |

| Реклама | За награду — только по явному действию игрока, игрок видит, что будет реклама | подсказка сверх бесплатной: значок рекламы на кнопке (`AdBadge`), реклама — по нажатию; награда — только по `onRewarded`; закрыл раньше — подсказки нет, тост «Подсказка откроется после просмотра рекламы» | код |
| Реклама | Игра не зависает, если реклама не пришла | не открылась за 8 с (`AD_OPEN_TIMEOUT_MS`) или ошибка — игра идёт дальше; вне Яндекса рекламы нет, подсказки бесплатные | код |

| Сохранения | Прогресс сохраняется и восстанавливается | локально (`user://` → IndexedDB) и в облаке `player.setData` после чтения облака; слияние с поколениями сброса (selftest «Поколения прогресса», «Таблицы лидеров после сброса») | код + черновик |

| Вход | Авторизация — только по действию игрока, игра доступна без входа | окно входа — только по нажатию: «ВОЙТИ» на экране лидеров (`leaders.gd` → `YSDK.open_auth`) и «Оценить игру» у гостя (12.10b) | код |
| Лидерборд | `setScore` не чаще раза в секунду | повторная отправка после входа — через 1,2 с (`RESUBMIT_GAP_SEC`); меньший счёт не отправляем (16.3) | код |

| Ярлык | — | не используем (убран 10.10, 16.2b) | — |
| Ссылки | Нет внешних ссылок и переходов | `OS.shell_open`, `window.open`, ссылок нет; JS — только SDK, `navigator.vibrate` (Android) и Метрика (16.1) | код |

| Страница | Игра сама не уходит в полный экран и не закрывается | полноэкранного режима и `quit()` в коде нет | код |
| Десктоп | Клавиши не зависят от раскладки, нет системных сочетаний; окно 16:9 и −20 %, масштаб 80–125 % | `physical_keycode` (R / Z / H, Ctrl+Z, Backspace); раскладки 13.0 — `docs/DESKTOP.md`, разделы 1 и 5 | код + черновик |
| Правила | Правила понятны без внешних инструкций | обучение уровней 1–3 (рука, подпись над полем), отмена и подсказка учатся, когда нужны | плейтест 16.7b |
| Готовность | Нет отладочных и недоделанных элементов | «ЛАБОРАТОРИЯ» в меню есть только в отладочной сборке (`OS.is_debug_build`); `tests/` в экспорт не входят (`exclude_filter`) | **экспорт без «Export With Debug»** |
| Техника | Работает во фрейме Яндекса без особых заголовков | `variant/thread_support=false` — `SharedArrayBuffer` и COOP/COEP не нужны | код |

## 2. Проверить в черновике (16.7a, одним заходом)

1. Сборка — **release** (в окне экспорта снять «Export With Debug»): в меню нет «ЛАБОРАТОРИИ».
2. Звук: свернуть вкладку, переключиться на другую, кликнуть мимо игры, межстраничная и реклама за награду — звук
   молчит и возвращается; настройки звука после этого прежние.
3. Реклама: межстраничная — только после «Далее» с 4-го уровня; за награду — подсказка сверх бесплатной; закрыть
   рекламу за награду раньше — подсказки нет, тост есть; игра не зависает, если рекламы нет.
4. Сохранения: пройти пару уровней, перезагрузить страницу — прогресс на месте; войти и открыть на другом устройстве —
   прогресс из облака.
5. Язык: `?lang=ru`, `?lang=en`, `?lang=tr` в адресе черновика — тексты на нужном языке, ничего не обрезано.
6. Страница: ПКМ по полю и по кнопкам — нет меню браузера; долгий тап на телефоне — нет выделения и лупы; страница не
   прокручивается и не «пружинит».
7. Десктоп — `docs/DESKTOP.md`, раздел 5 (16:9, −20 %, 5:4, 21:9; масштаб 80–125 %; R / Z / H в русской раскладке).
8. Телефон в портрете — как раньше; в альбомной ориентации — заглушка SDK «поверните экран» (в черновике
   «Ориентация: Портретная»).
9. Вход: игра целиком доступна гостю; окно входа — только кнопкой на экране лидеров.
10. Консоль браузера: нет красных ошибок при старте, рекламе и смене сцен.

## 3. Заполнить в консоли (вместе с 16.5 и 16.7)

- Платформы: «Десктоп» и «Мобильные»; ориентация — «Портретная».
- Возрастной рейтинг — **решение** (по содержанию игры подходит 0+).
- Лидерборды `score` и `daily_streak` (README, «Функции Яндекса»); Remote Config — три флага (README, «Remote Config»).
- Номер счётчика Метрики — `METRIKA_ID` в `web/shell.html` (16.1): **вписан 22.10 — 113726044**, 19 целей заведены;
  осталась проверка целей в черновике (`_ym_debug=1`).
- Промо (16.5): тексты ru / en / tr — `docs/PROMO.md` (проверка `tools/promo_check.py`); иконка, обложка, скриншоты
  (десктопные — только 16:9, геймплей не меньше 70 %).
- «Общее» черновика (11.10 там стоит ориентация «Любая» — поменять): платформы, ориентация «Портретная», языки
  ru / en / tr, облачные сохранения — включить; «Комментарий разработчика» для модераторов (реклама, сохранения,
  лидерборды, управление), ключевые слова и теги — `docs/PROMO.md`, раздел «Общее».
