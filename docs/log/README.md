## Как переносить дальше
- Этап закрыт: его раздел с `[x]` из корня → `docs/log/stage_NN.md`, записи лога этапа → `docs/log/journal_NN_ДАТЫ.md`
  (номер — следующий по порядку). В начале файла — строка «Вынесено из корневого PROGRESS.md ДАТА». Строку в
  таблицу выше.
- Корень подбирается к 40 КБ посреди этапа: старые записи лога этапа → `journal_NN_…`. Чек-лист этапа остаётся в
  корне до закрытия этапа.
- Файл архива не больше ≈ 50 КБ: агент читает его целиком, а `files edit` не правит файлы больше 50 КБ.
- `tools/save.py --pull` различает копии проекта по последней строке `- …` корневого `PROGRESS.md`. Поэтому лог в
  корне должен оставаться списком записей с `- `.
