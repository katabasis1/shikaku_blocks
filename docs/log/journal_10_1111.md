## 11.11.2026 — selftest у пользователя: «Nonexistent function '_on_undo_pressed' in base 'Control (Game)'»
- Причина: `_test_analytics` (16.1) жал убранную в 20.1a «Отмену». `check_gd` это пропустил: переменную
  `var game := ps.instantiate() as Game` он не считал переменной с типом `Game`. Теперь считает (тип из «as Класс»
  в конце строки); заодно в `BUILTINS` — `is_visible_in_tree`, `toggle_mode`, `set_pressed_no_signal`, `get_node`.
  Новая проверка нашла только этот вызов.
- `_test_analytics`: тупиковый ход — ошибка, блок назад `flush_mistake`; целей `undo` — 0, в итоге «Заново» `undo` — 0.
- Тем же поиском по «отмене» в selftest: `_check_level_sounds` ждал `Audio.UNDO` 1 раз — теперь 0; `Audio.ERROR` —
  1, только если ошибочный блок дождался трещины (проба с нажатием на лоток возвращает его раньше — тогда 0,
  `_logic_error_sounds`). Список подписей в проверке Toast — как `TOAST_TEXTS` (подписи про отмену убраны).
- `check_gd` — 0 проблем, модель — всё сходится. **Нужен повторный прогон selftest** у пользователя.
